# Fonts

Self-hosted so the invitation renders identically for every guest, with no
request to a third party and no dependency on Google Fonts being reachable.
Latin and Latin-Extended subsets only. Everything else was stripped, which is
why these are small.

| **Jost** | all UI text, buttons, labels, spaced caps | © 2020 The Jost Project Authors |
| **Cormorant Garamond** | section headings, numerals, quoted messages | © 2015 The Cormorant Project Authors |

All three are licensed under the **SIL Open Font License, Version 1.1**. See
[`OFL.txt`](OFL.txt). The OFL permits redistribution and use in this way,
including on a public website, provided the license travels with the fonts.
That's what this folder does.

Declared in [`../css/fonts.css`](../css/fonts.css), which is generated. If you
ever swap a family, regenerate rather than hand-editing.
